**WHATS INSIDE**
This repository contains my work for the Artificial Intelligence (AI) course of my degree program. It brings together intelligent agents, core AI algorithms, decision tree construction, supporting calculations, and tests, 
all implemented as hands-on practice of the concepts covered in class.

 
**Topic	Description**
🧠 Agents	Implementations of intelligent agents and how they perceive and act in an environment.
⚙️ Algorithms	Core AI algorithms implemented from scratch, such as search and problem-solving techniques.
🌳 Decision Tree Making	Building decision trees step by step, including attribute selection and tree construction.
🧮 Calculations	Worked calculations behind the algorithms (e.g. entropy, information gain, heuristics, costs).
✅ Tests	Test cases to verify that the agents, algorithms, and calculations work correctly.

**🎯 LEARNING OUTCOMES**
Through this course and repository, I practiced:
-Understanding how intelligent agents perceive, decide, and act
-Implementing classic AI algorithms in code
-Constructing decision trees using entropy and information gain
